description: |
  Je développe une application avec une interface graphique (GUI) personnalisée pour un appareil IoT Core S3. L'appareil envoye des données via MQTT au travers du Wifi dont les identifiants sont provisionnés par BLE.
  Le Core S3 ne dispose pas de framework GUI intégré, j’ai conçu entièrement l’interface et les interactions moi-même : composants visuels, boutons, icônes, navigation et enchaînement des écrans, ainsi que les différents fonctionnements des systèmes.
