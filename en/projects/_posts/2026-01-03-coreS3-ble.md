  Developing a custom GUI application for a Core S3 IoT device to configure connectivity and transmit data over MQTT. Wifi credentials are securely provisioned via BLE. Since the Core S3 has no built-in GUI framework, I implemented all interface components and interaction logic from scratch, including buttons, icons, and system workflows.
